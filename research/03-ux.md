# UX первого рабочего среза

Независимый агент №3 · 29 октября 2026 · источник: `docs/01-product.md`, `docs/02-ux.md` исходного проекта.

## Что установлено документами

Это закрытый рабочий инструмент компании для передачи опыта мастера. Первый полезный сценарий — найти опубликованную инструкцию и перейти к нужному фрагменту либо вручную разметить собственное видео. Открытый маркетинговый сайт, мобильное native-приложение, платежи и автоматическая публикация не входят в D1. Основной язык интерфейса — русский. Минимальная ширина — 360 px.

Пилотная отрасль и компания ещё не подтверждены. Названия цехов, инструкции и люди в демо должны быть прямо обозначены как демонстрационные данные; нельзя выдавать их за настоящего клиента.

## Рекомендуемый первый интерфейс

Режим поверхности — Operate. Главная композиция: компактная служебная навигация, библиотека, ясная кнопка «Новая инструкция». Не открывать продукт аналитическим дашбордом: для метрик ещё нет данных, а первичная задача — найти ответ или загрузить запись.

1. **Библиотека.** Заголовок «Инструкции» с коротким пояснением, кнопка создания, полноразмерный поиск, вкладки «Опубликованные / Черновики / На проверке / Скрытые» для авторских ролей, фильтр языка. Карточки имеют название до двух строк, цель, количество шагов, язык, дату, автора и необязательную обложку. Отсутствие обложки не оставляет пустой огромный прямоугольник. Сортировка по свежей публикации. Не изображать внутренние категории как готовое серверное свойство, если их нет в модели.
2. **Создание.** Одна форма: название, цель, язык записи, файл, подтверждение прав. Лимиты 500 MiB / 10 минут и форматы MP4/MOV показываются до выбора. Подсказка: «Произносите вслух названия действий и предметов». Фактический процент относится только к передаче файла. После загрузки можно уйти в библиотеку; до её завершения — предупреждение при уходе.
3. **Редактор.** На desktop видео слева (~45%), список шагов справа; заголовок и статус сохранения над ними. У шагов номер, заголовок, описание, начало/конец, «Взять текущее время», «Выше/Ниже», «Проверено». Расшифровка — отдельная вкладка, не третья узкая колонка. На мобильном видео выше шагов. Редактор ограничен 30 шагами и реальной длительностью видео.
4. **Чтение.** Заголовок, цель и сведения о проверенной версии; видео и компактный список шагов. Выбор шага меняет текущий момент без автовоспроизведения. Явная кнопка запуска фрагмента. На телефоне выбранный шаг и его фрагмент остаются рядом; пользователь не должен прокручивать всю страницу после каждого выбора.

## Предлагаемая визуальная основа — рекомендация, не утверждённый бренд

Умеренно тёплый производственный инструмент: светлая поверхность, графитовый текст, тёмный зелёный для основных действий, охра только для ожидания и внимания. Не использовать декоративные градиенты, стекло и рекламные обещания.

| Роль | Цвет |
|---|---|
| Фон приложения | `#F6F5F1` |
| Основная поверхность | `#FFFFFF` |
| Основной текст | `#202A25` |
| Вторичный текст | `#626C65` |
| Границы | `#DEE3DC` |
| Основное действие | `#275C47` |
| Мягкое выделение | `#E8F0EA` |
| Предупреждение: текст | `#815218` |
| Предупреждение: фон | `#FFF2D8` |
| Ошибка: текст | `#A72F2F` |

Системный sans-serif с хорошей кириллицей. Основной текст 15–16 px, заголовок экрана 30–32 px, заголовок карточки 18–20 px. Числа времени табличные. Размеры касаний минимум 44×44 px, явный контрастный focus ring. Радиусы сдержанные: 8 px у контролов, 12 px у карточек. У статусов обязательно текст и/или знак вместе с цветом. Длинное название организации и кириллица не ломают верхнюю панель.

Desktop: служебная панель 220–240 px, основной контент максимум 1240 px; библиотека 2–3 колонки по доступной ширине. Tablet: навигация сворачивается, 2 колонки. Телефон: одна колонка и компактная верхняя панель, основная кнопка доступна без горизонтальной прокрутки. Это рекомендации для проверки в браузере, а не обязательные абсолютные размеры.

## Состояния, которые нельзя пропустить

- Пустая библиотека автора: «Загрузите первое видео и соберите инструкцию». Читателя: «Здесь появятся инструкции после публикации».
- Ничего по поиску: показать запрос и «Сбросить фильтры». Ошибка сети получает повтор запроса, а не пустую выдачу.
- Обработка: именованные стадии, без искусственного процента. Внешний ИИ отключён: «Автоматическое составление шагов пока не подключено», доступна ручная работа, если видео готово.
- Сохранение: «Сохраняем…», «Сохранено», «Изменения ещё не сохранены». При 412 остановить autosave и предложить скопировать локальный текст/загрузить актуальную версию. Не перезаписывать молча.
- Недопустимый таймкод: ошибка возле поля, переход фокуса к первой ошибке. Формальное ограничение: `0 ≤ начало < конец ≤ длительность`.
- Отправка на проверку после подтверждённого сохранения; опубликованный документ неизменяем, новый черновик не заменяет его у читателя.
- Функции, которых ещё нет в первом срезе, не изображать рабочими кнопками с фиктивным toast. Лучше отсутствующий пункт или явное описание границы реализации.

## Приёмка UX

Проверить ширины 360/390/768/1440 px и управление с клавиатуры. Новичок открывает инструкцию и выбирает шаг без просмотра всего видео; автор создаёт и переупорядочивает ручные шаги без drag-and-drop. Локальные действия не выдаются за серверное сохранение, неподключённый ИИ — за выполненную обработку. Воспроизведение начинается только по действию пользователя.
