# Браузерная приёмка первого среза

29 октября 2026, Asia/Almaty. Выполнил основной агент через встроенный браузер Codex и реальный Django API. Это локальный synthetic-only тест, не приёмка реальной компанией.

## Фактически пройдено

1. Вход admin через CSRF-защищённую форму; загрузка библиотеки из API.
2. Создание «Проверка комплекта перед передачей» с синтетическим источником 60 секунд.
3. Добавление четырёх шагов с интервалами 0–15/15–30/30–45/45–60 секунд; сохранение. Перезагрузка страницы сохраняет ранее введённые шаги и серверную ревизию.
4. Отправка на проверку блокирует поля. Все четыре отметки записаны сервером; публикация доступна после пяти общих подтверждений.
5. Публикация создала версию 1. Переход к второму шагу установил `video.currentTime=15`, `paused=true`; длительность видео 60, `readyState=4`. Источник отдаётся через защищённый Range route.
6. Создание нового черновика не изменило опубликованную версию.
7. Два окна открыли одинаковую ревизию. Первое сохранило изменения; второе получило 412. На экране второго окна сохранился локальный текст и доступен диалог с полной копией JSON; тихой перезаписи нет.
8. Вход reader: нет кнопок создания и редактирования, нет черновика из seed в библиотеке. Публикация версии 1 показывает исходный текст, хотя рабочий черновик уже изменён.
9. Reader проверен на 1440, 768, 390, 360px: ширина документа совпадает с viewport, горизонтального overflow нет. Мобильные элементы остаются читаемыми. Это эмуляция размеров встроенного браузера, не Safari iOS/Chrome Android на физических телефонах.
10. После заключительной сборки отображаются корректные склонения («4 шага») и имя проверяющего. Доступное имя диалогов задано явно.

## Итоговые проверки

`make check` — PASS: 33 backend tests, 5 frontend tests, Django system check, migration drift, validation исходного плана, TypeScript, production build. PostgreSQL, конкурентные транзакции, удалённый GitHub Actions и реальные устройства не запускались.

Сборка запущена одной командой `.venv/bin/python scripts/dev.py --preview`: порт 4173, API 8000. Повторная подготовка сохранила существующие данные. Dev/HMR на 5173 во встроенном браузере не удалось подтвердить: production preview отрабатывает весь маршрут. Для просмотра текущего результата используется preview.

## Что не заявлено проверенным

Полная клавиатурная/screen-reader приёмка, медленная/обрывающаяся сеть, истечение сессии с dirty editor в браузере, пагинационная гонка под задержками, все формы на всех ширинах, реальный media pipeline и производственная нагрузка. Исправления пагинации и повторного входа проверены по коду и сборкой, а не отдельной браузерной симуляцией.
