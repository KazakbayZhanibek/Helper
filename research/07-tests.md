# Независимые проверки серверного среза

Агент №7 · 29 октября 2026. Код приложения не изменялся этим агентом; тесты созданы независимо от seed-команды и пользовательской базы.

## Фактический результат

Команда из корня проекта: `.venv/bin/python -m pytest -q`.

Последний прогон после исправлений: **33 passed**. Окружение: Python 3.12, Django 5.2.18, DRF 3.18.3, pytest 9.2, SQLite in-memory. Тесты используют изолированное приватное хранилище с тестовыми байтами; реальное видео не декодируют. Для скорости только в тестовых settings выбран MD5 password hasher; runtime-настройки приложения не изменены.

## Покрытие

- Реальный сессионный вход с обязательным CSRF, logout с CSRF, истечение доступа после выхода; нейтральный ошибочный login и ограничение попыток.
- 401 без сессии, Request ID и private/no-store; reader не получает черновик, рабочую копию, историю или его видео; author не публикует и не проверяет шаги.
- Подмена организации и ID объектов возвращает 404; отзыв membership и приостановка организации действуют на следующем запросе.
- If-Match обязателен; устаревшее изменение отклоняется без потери сохранённого текста; порядок меняется со стабильными ID; чужие и повторные ID шагов запрещены.
- Границы времени, тип integer без bool/float, недопустимый язык, сверхбольшие интервалы; подделка проверяющего и AI-происхождения запрещена.
- Редактирование на проверке закрыто; возврат требует причины и сбрасывает отметки; публикация требует ready source, проверенные шаги и пять точных подтверждений.
- Идемпотентность создания и публикации; другой payload с тем же ключом даёт 409; новый черновик не меняет опубликованный snapshot и не попадает в поиск читателя.
- Отзыв публикации закрывает читателю поиск, страницу и видео, сохраняя историю.
- Прямые DB-записи не обходят межорганизационные ограничения, принадлежность current_version своей инструкции и неизменяемость PublishedVersion.
- Видео: точный Range 206, suffix Range, HEAD, ошибки 416, чрезмерно длинный Range; путь за пределы private root не выдаётся.

## Найденные и исправленные дефекты

1. `language: []` или `{}` вызывал TypeError и 500. Root добавил проверку строкового типа; сохранён regression test.
2. Security-review агент обнаружил `end_ms=10**100` без источника: значение доходило до БД и вызывало OverflowError. Root добавил общий предел 600000 ms; regression подтверждает 400 без изменения ревизии.
3. Security-review агент обнаружил Range с 4400 цифрами: преобразование int вызывало 500. Root ограничил длину числовых частей; regression подтверждает 416.

## Границы результата

PostgreSQL, параллельные транзакции, браузеры, реальная загрузка/декодирование, backup/restore, worker и внешний ИИ этим набором не проверены. Успех тестов подтверждает локальный ручной срез, не завершение D0 и не готовность к production.
