# Независимая проверка безопасности — агент 8

29 октября 2026. Проверены `backend/core/{models,services,views,http}.py`, настройки, маршруты и DB guards в миграции 0002 относительно документов 04/05/07. Код приложения не изменял; исправления выполнил основной агент. Все динамические проверки использовали отдельную SQLite `:memory:` с применёнными миграциями, не рабочую демонстрационную базу.

## Найдено и исправлено

| Сценарий | До исправления | Проверка после исправления |
|---|---|---|
| POST инструкции с `language: []` или `{}` | HTTP 500: unhashable value в проверке множества языков | HTTP 400, `VALIDATION_ERROR` для обоих типов |
| Инструкция без источника, PUT шага с `end_ms=10**100` | HTTP 500: integer overflow при записи, поскольку предел времени проверялся только при наличии asset | HTTP 400, `INVALID_TIME_RANGE`; предел 600000 мс применяется независимо от источника |
| Playback с заголовком Range, содержащим 4400 цифр | HTTP 500: Python ограничивает число цифр при преобразовании `int` | HTTP 416 после ограничения числовой части |

Первоначальные сбои и итоговые статусы воспроизведены через Django Client. Негативные сценарии переданы агенту 7 для постоянных регрессионных тестов.

## Результат чтения кода

- Tenant-объекты запрашиваются через активное membership; читатель получает только текущую публикацию и не получает рабочую копию.
- Роли проверяются серверными views до изменения; поля роли, происхождения, проверяющего и состояния клиентом не принимаются.
- Login отдельно защищён CSRF; session auth проверяет CSRF для остальных изменений. Ответы получают `private, no-store` и request ID.
- Публикация проверяет ревизию, состояние проверки, источник и отметки шагов; повторы защищены idempotency scope.
- Записи snapshot защищены от UPDATE на уровне БД, включая bulk ORM. Триггеры также контролируют tenant/source/current-version связи и запрещают смену источника.
- Playback использует серверный storage key и проверку пути внутри приватного корня, активной организации и текущей публикации читателя. Прямой публичный media route отсутствует.

В рассмотренной области не воспроизведён обход межорганизационного доступа, роли публикации или чтения черновика. Это ограниченный review, не заявление об отсутствии уязвимостей.

## Границы проверки

PostgreSQL-ветка миграций и реальные конкурентные транзакции здесь не запускались. SQLite не доказывает корректность PostgreSQL-блокировок. Локальный cache-limiter входа и development server не предназначены для production.

Реальные загрузки, worker, приглашения, reset, review comments/blockers, удаление и эксплуатационная инфраструктура исключены из данного среза и не представлены как реализованные. Полная серверная матрица ролей/workflow проверяется отдельным набором `backend/tests` агента 7.
