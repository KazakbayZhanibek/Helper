# Агент 05 — frontend первого ручного среза

Реализовано в `frontend/src` на React 19.3.1, TypeScript 7.0.2 и Vite 8.3.5:

- Настоящий вход в Django session, CSRF, роль и организация от сервера. Локальные demo-buttons доступны только в dev при VITE_DEMO_PASSWORD.
- Библиотека, поиск с задержкой 300 мс и отменой устаревших запросов, status/language в URL, состояния loading/error/empty, пагинация защищена generation+abort.
- Создание ручного черновика с синтетическим source только в demo_mode; без фиктивной загрузки собственных файлов.
- Редактор названия/цели/языка, шагов/таймкодов, перестановка и удаление, HTML video. Сохранение через API, ETag и автоcохранение с задержкой 1500 мс; на время запроса поля блокируются, второй запрос не отправляется.
- При 412 локальный текст остаётся, есть диалог копирования и явная перезагрузка. При 401 повторный вход происходит в modal без уничтожения открытого редактора.
- Проверка и публикация: отдельные отметки шагов серверными командами, общие подтверждения, возврат с причиной, авторский отзыв запроса. Происхождение шага не редактируется клиентом.
- Чтение immutable publication, выбор шага без autoplay, явное воспроизведение, остановка на конце шага, новая рабочая версия, список версий и отзыв публикации по роли.
- Общий responsive интерфейс cream/pine, мобильные состояния, labels, visible focus, native dialog, reduced-motion, нет внешних шрифтов/изображений.

Проверено: `npm run build` (TypeScript + Vite) проходит. npm install audit: 0 vulnerabilities. Браузерную сквозную проверку выполняет основной агент отдельно — этот отчёт её не утверждает.

Независимые находки агента 10 исправлены: race pagination, истечение session/logout 401, перенос минуты при форматировании 59999 мс. Изменения форматированы Prettier.

Ограничения: нет реального upload/ASR/AI, приглашений/reset, feedback/deletion. RU строки пока находятся в компонентах, перевод KK отложен. История показывает список снимков; отдельного браузера произвольных исторических snapshots пока нет. Local dev не равен полному D0.
