# Продукт и требования

[К полному плану](00-overview.md)

## Проблема и первая аудитория

Рабочая гипотеза: опытный сотрудник повторно объясняет одни и те же операции, а новичок не может быстро найти проверенный ответ. Сначала проверяем её на комплектации, упаковке или проверке заказов одной компании. Это пример сегмента для пилота, а не уже выбранный партнёр.

Первая ценность: уменьшить время подготовки понятной инструкции и поиска нужного шага. Польза должна сохраняться при ручной разметке видео. Наличие ИИ само по себе не считается результатом.

| Пользователь | Его задача | Критерий удобства |
|---|---|---|
| Мастер/автор | Зафиксировать порядок работы, не занимаясь монтажом | Исправляет черновик быстрее, чем собирает инструкцию привычным способом |
| Проверяющий | Проверить точность и опубликовать | Видит исходное видео, все шаги, замечания и конкретную версию |
| Сотрудник/читатель | Найти ответ во время работы | Открывает правильный шаг без просмотра всего ролика |
| Администратор организации | Управлять доступом и актуальностью | Может отключить участника, скрыть инструкцию и удалить данные |

В небольшой компании один человек может совмещать роли автора, проверяющего и администратора. Это организационная возможность, а не скрытая автоматическая публикация.

## Пилотные ограничения

Предлагаемые начальные лимиты конфигурируются сервером и показываются до загрузки: 1 организация пилота, до 20 участников, 50 источников, видео от 10 секунд до 10 минут, до 500 MiB на файл, суммарно 20 GiB исходников. Отдельный лимит диска учитывает ещё производные файлы и временную обработку. Это инженерные допущения, не тарифный план.

Форматы ввода: MP4 и MOV с одной видеодорожкой, допустимыми H.264/HEVC и аудио AAC/PCM при успешной проверке декодером. Отсутствие звука разрешает ручную работу. Поворот телефона должен учитываться. Вывод — совместимый MP4/H.264/AAC до 720p для первого пилота. Ограничение входа: большая сторона ≤3840 px, меньшая ≤2160 px, включая портретный ролик; некорректная длительность отклоняется до дорогой обработки. Подробно — документ 06.

Первый интерфейс — русский. Расшифровку разрешается выбрать русскую, казахскую или смешанную; качество оценивается отдельно. Автоматический перевод, озвучивание и обещание одинаковой точности всех языков не входят в D1.

## Функциональные требования

| ID | Требование | Проверяемый результат |
|---|---|---|
| FR01 | Вход по приглашению, восстановление доступа | Чужой человек не может зарегистрироваться в организации самостоятельно |
| FR02 | Роли admin, author, reviewer, reader | Сервер разрешает действия по матрице документа 07 |
| FR03 | Изоляция организаций | Подмена UUID организации/файла не раскрывает чужой объект |
| FR04 | Отключение участника | На следующем запросе защищённые данные ему недоступны |
| FR05 | Создание инструкции | Заголовок, цель, язык, источник, владелец и статус сохраняются |
| FR06 | Загрузка и отмена | Процент относится только к передаче файла; отмена очищает незавершённый источник |
| FR07 | Проверка файла и лимитов | Неподдерживаемый или слишком большой файл не попадает в обработку |
| FR08 | Фоновая обработка | Обновление страницы сохраняет состояние; пользователь может уйти со страницы |
| FR09 | Ошибка, повтор и ручной путь | Отказ модели не уничтожает видео и ручные шаги |
| FR10 | Просмотр видео | Воспроизведение, пауза, перемотка, скорость, полноэкранный режим, загрузка по диапазонам |
| FR11 | Расшифровка с таймкодами | Каждый фрагмент открывает соответствующий момент; исходный текст хранится отдельно от правки |
| FR12 | Черновик шагов от ИИ | Текст соответствует источнику, сомнительные места помечены, схема валидна |
| FR13 | Ручной редактор | Добавление, изменение, удаление и переупорядочивание шагов без ИИ |
| FR14 | Изменение времени шага | Проверено 0 ≤ начало < конец ≤ длительность видео |
| FR15 | Сохранение без потери чужой правки | Ревизия и If-Match предотвращают молчаливое перезаписывание |
| FR16 | Предварительный просмотр | Автор видит ту же последовательность, что получит читатель |
| FR17 | Передача на проверку | Ревизия блокируется для редактирования; замечания привязаны к версии/шагу |
| FR18 | Возврат на доработку | Причина возврата обязательна; повторная отправка создаёт новый цикл проверки |
| FR19 | Публикация человеком | Зафиксированы проверяющий, версия, время и подтверждённые проверки |
| FR20 | Неизменяемая опубликованная версия | Правка создаёт новый черновик; читатель видит старую версию до новой публикации |
| FR21 | Отзыв публикации | Администратор или проверяющий может немедленно скрыть текущую инструкцию |
| FR22 | Библиотека и поиск | Выдача читателя содержит только доступные текущие публикации |
| FR23 | QR-код и ссылка | После входа открывается нужная инструкция; URL не является ключом доступа |
| FR24 | Мобильное чтение | Один шаг и связанный фрагмент доступны без горизонтальной прокрутки |
| FR25 | Сообщение об ошибке | Читатель указывает проблемный шаг и описание, автор видит запись |
| FR26 | Удаление инструкции и медиа | Доступ прекращается сразу, физическая очистка завершается контролируемой задачей |
| FR27 | События и журнал | Значимые действия фиксируются без полного содержимого видео/расшифровки |
| FR28 | Ограничение расходов | Вызов ИИ не выполняется при отключённом провайдере или превышенном лимите |
| FR29 | Согласованный режим обработки | Внешний ИИ получает только разрешённый набор данных; отправка выключена по умолчанию |
| FR30 | Приёмка и эксплуатация | Восстановление из резервной копии и сквозной пилот реально проверены |

## Нефункциональные цели

Это исходные цели, которые проверяются на согласованной конфигурации пилота, а не обещания для любой нагрузки.

| ID | Цель | Как измерять |
|---|---|---|
| NF01 | Отсутствие доступа между организациями | Негативные API-тесты для каждой сущности, медиа и поиска |
| NF02 | API метаданных p95 ≤ 800 мс | 10 одновременных активных пользователей; исключены загрузка/медиа/ИИ |
| NF03 | Поиск p95 ≤ 1 с | 100 опубликованных инструкций тестового набора; фильтр прав включён |
| NF04 | Сохранение формы p95 ≤ 1 с | Ответ API на небольшую инструкцию, без передачи видео |
| NF05 | Основной сценарий доступен с клавиатуры | Ручная проверка фокуса, диалогов, форм и ошибок |
| NF06 | Мобильная ширина от 360 px | Нет горизонтальной прокрутки основного сценария, кнопки доступны |
| NF07 | Асинхронная обработка измеряется честно | Показывается стадия и очередь, а не выдуманный процент готовности |
| NF08 | Никакой молчаливой потери правок | Конфликт выдаёт 412; сохранение и публикация проверяют ревизию |
| NF09 | Данные восстанавливаются | Цель пилота RPO ≤ 24 ч, RTO ≤ 4 ч; подтверждается репетицией |
| NF10 | Предсказуемые ресурсы | Один media/AI job одновременно на исходной конфигурации; лимиты CPU/RAM/диска |
| NF11 | Наблюдаемость ошибок | У каждого запроса/задания есть request_id/job_id; доступна причина и действие |
| NF12 | Расходы ограничены | Серверный дневной лимит, счётчик потребления, ручное выключение провайдера |

## Что откладываем после первой версии

Чат по инструкциям, семантический поиск, перевод, синтез речи, мобильные приложения, офлайн-кэш видео, платежи, открытая регистрация, собственная большая модель, распознавание всех действий по видео, интеграции с ERP, аналитика эффективности отдельных сотрудников, несколько исходных роликов в одной инструкции. Их отсутствие не мешает проверить основную ценность.

## Пример завершённого сценария

Мастер записал двухминутную комплектацию набора и вслух назвал действия. Загрузил файл, выбрал язык и увидел черновик из пяти шагов. Исправил название одного предмета, разделил длинный шаг, проверил таймкоды, отправил на проверку. Проверяющий просмотрел исходник и опубликовал версию 1. Сотрудник открыл QR-код, вошёл, нашёл «проверка комплекта» и увидел четвёртый шаг. После замечания автора создаётся версия 2; версия 1 остаётся текущей, пока версия 2 не утверждена.

## Когда не продолжать расширение

Если нет доступа к настоящим пользователям, тестировать интерфейс и технический процесс на собственных разрешённых роликах, но не объявлять подтверждённый спрос. Если редактура ИИ стабильно занимает больше времени, чем ручная разметка, сначала исправить черновики или оставить ручной режим. Если пользователи не возвращаются к инструкциям, пересмотреть выбранный рабочий процесс до интеграций и масштабирования.
