## Что реализовано

Локальное приложение поддерживает маршрут: вход → загрузка MP4/MOV/WebM или запись камеры → подготовка сохранённого видео → ручная разметка, локальная расшифровка либо визуальное предложение → явное применение → проверка мастером → публикация → чтение. Ручная разметка остаётся доступной независимо от ИИ. Сессии, доступ, содержимое, ревизии и задания обслуживает Django API.

Для локального теста выбран **whisper.cpp + Codex CLI с `gpt-6-luna` через существующий вход ChatGPT**. Это облачная обработка OpenAI с лимитами подписки, только для доверенного localhost-запуска. Прямые API-адаптеры OpenAI `gpt-5.4-mini` и NVIDIA API Catalog сохранены. Учебная организация разрешила внешнюю обработку; отдельное согласие на кадры сохраняется. Загрузка MP4 и ASR проверены реальным выполнением. После добавления ключа OpenAI API вернул `credit_balance_exhausted`; отдельный вызов Codex распознал красный JPEG. Сквозной путь настоящего видео подтверждён на публичном ролике Pexels: 20,96 с без звука, 12 кадров, 4 действия, сохранённые в черновик. Физическая камера и микрофон ещё не проверены.

Визуальный ИИ получает реальные уменьшенные JPEG только после отдельного согласия на изображения. Во время записи он показывает предварительные наблюдения: их нельзя применить к инструкции, а время отсчитывается от подключения наблюдения. Остановленная запись при включённом переключателе восстановления сохраняется в IndexedDB браузера на 24 часа для того же аккаунта, организации и инструкции. При закрытии страницы во время записи незавершённое видео не восстанавливается. После сохранения выполняется новый анализ кадров, привязанный к серверному видео. По умолчанию он охватывает всю запись обзорными окнами по 30 секунд и до 12 кадров в каждом, затем уточняет неясное одним уровнем окон до 15 секунд в пределах бюджета; пропуски движения и приблизительное время явно указаны. Автор может подтвердить добавление или замену шагов, но не автоматическую публикацию.

Тесты с подменённым провайдером не подтверждают облачную доступность или смысловую точность шагов.

Озвученный ролик создан локально как синтетический тест, без записи реального предприятия или личного голоса. Его успешная расшифровка не доказывает качество на шумной производственной записи.

## Явные отклонения от исходного проекта

- **Очередь:** вместо Celery/Redis сейчас одна долговечная очередь в БД и `processing_worker`. В SQLite допускается один worker. Это осознанный локальный этап; многопроцессная производственная работа не проверена.
- **Передача:** содержимое файла отправляется `application/octet-stream`, а не multipart. Метаданные, права и размер проверяются до чтения потока; [контракт](../research/14-media-contract.md).
- **Выдача медиа:** закрытый Django API с Range/HEAD пока обслуживает файл напрямую. Nginx internal delivery ещё не настроен.
- **ИИ:** локальный Whisper и тестовый Codex CLI с `gpt-6-luna` выбраны явно; прямые OpenAI/NVIDIA API остаются альтернативами с отдельными ключами. Codex запускается только при `DJANGO_DEBUG=1`, `DEMO_MODE=1`, `CODEX_TEST_MODE=1`, с существующим входом ChatGPT, без передачи API-ключей и без извлечения файлов авторизации. Это локальный тест, не производственный сервер. Текстовый запрос содержит расшифровку; визуальный — реальные JPEG, UUID и время кадров после отдельного согласия. Полный видеофайл и аудиофайл провайдеру не отправляются. Автоматического скачивания модели, запасного провайдера, применения или публикации нет.
- **Выборка:** визуальный анализ не наблюдает непрерывное движение. Live-время не переносится в сохранённый ролик; предложения по видео получают приблизительные интервалы из кадров и требуют проверки человеком.
- **Хранение кадров:** maintenance worker и команда `cleanup_visual_sessions` удаляют неиспользованные live-кадры после `expires_at + 1 час`, uploaded-кадры — через 7 суток от создания сеанса. Активные задания и применённые evidence сохраняются; это не удаление всей инструкции или текста наблюдений.
- **Бюджет:** внутренний ledger реализован: атомарные резервы сеанса, организации (UTC-день/месяц) и платформы (UTC-день), квоты обращений, settlement независимо от отмены и удержание unknown. Денежный адаптер только для OpenAI `gpt-5.4-mini`; неизвестный тариф, включая NVIDIA, блокирует запрос. Codex учитывается в subscription_calls без выдуманного USD. Платные списания, PostgreSQL-конкурентность и операционная сверка ещё не приняты; коммерческие тарифы и платежи не реализованы.

## Остаток до локального пилота

1. **Принять бюджет на платном API и измерить себестоимость.** Реестр и ограничения уже реализованы; остаются платный billing E2E, PostgreSQL-гонки, сверка unknown и provider project limits. [Реализованный бюджет и проект экономики](04-data.md#реализованный-бюджет-и-проект-экономики) отделяет внутренние потолки от неутверждённых клиентских тарифов. Экономный live 30 секунд / 20 вызовов, общий кеш и пополнение остаются проектом.
2. **Замкнуть камерный сценарий и устойчивость.** На физической камере пройти запись → остановку → просмотр/скачивание → загрузку → новый анализ. Проверить отказ разрешения, работу без микрофона, выключение устройства и сетевые сбои; затем append/replace и ручную проверку. Восстановление остановленного файла после обновления и история применённого ИИ-ответа уже подтверждены отдельно. Подача кадров готового ролика в live API не проверяет устройство и MediaRecorder.
3. **Измерить полезность и расходы на рабочих записях.** Подготовить несколько разрешённых видео с ручной разметкой действий, включая речь, перекрытие рук и быстрые движения; отдельно пройти текстовый ИИ по расшифровке. Зафиксировать пропуски, ошибки времени, задержку, стоимость полезной инструкции с retries и удобство для автора/проверяющего. Один ролик с лодкой этого набора не заменяет.
