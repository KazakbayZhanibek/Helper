# Визуальная основа первого среза

Рабочее направление для реализации, выбранное из контекста проекта; отдельное пользовательское утверждение бренда не получено.

- Поверхность: закрытый рабочий инструмент. Библиотека и поиск — первая страница после входа.
- Фон #F7F6F2, текст #26382E, основное действие #28624A; мягкий зелёный и сдержанный лайм только для акцентов.
- Системный sans с хорошей кириллицей. Время — табличные цифры. Заголовки сильные, основной текст 15–16px.
- Desktop: боковая панель 220px, редактор видео слева/шаги справа. Телефон: видео над шагами, размер касаний от 44px.
- Состояния выражаются словами, не только цветом. Видимый клавиатурный фокус и подписи полей обязательны.
- Пустая выдача, ошибка загрузки данных, несохранённая форма и конфликт ревизии — отдельные состояния.
- ИИ отключён; непостроенные функции не выдаются за рабочие кнопки.

Подробный [UX brief](research/03-ux.md). Визуальные изображения в design — концепты, не скриншоты работающего приложения.
