# Интерфейс «Рецептов мастера»

На главной странице посетитель может открыть готовый видеорецепт, создать кухню или войти. После входа открывается книга выбранной кухни. Основное действие автора в книге — добавить рецепт. Для первого сохранения достаточно названия блюда.

- В верхнем меню доступны рецепты. Администратор также видит команду и подписку. Смена кухни и выход находятся в меню аккаунта. Оператор открывает список клиентов отдельно.
- В редакторе видео находится рядом с карточкой блюда, на телефоне — над ней. Ссылки ведут к видео, ингредиентам и шагам. Настройки обработки открываются по запросу.
- При готовке читатель видит текущий шаг, кадр и соответствующий отрывок записи. Кнопки перехода должны помещаться на экране шириной 320 пикселей.
- Основные цвета книги заданы переменными в `frontend/src/recipe-shell.css`. Фон тёплый светлый, основной текст тёмный, кнопки действий зелёные. Статусы подписки, публикации и сохранения подписаны словами.
- Для форм используются видимые подписи, клавиатурный фокус и пояснения об ошибках рядом с полями. На маленьком экране меню кухни занимает отдельную строку.

Исторические концепты первой версии сохранены в [исходном описании интерфейса](research/03-ux.md).
