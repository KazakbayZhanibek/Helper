# Рецепты мастера

Кулинарная книга для команды или семьи. Автор снимает приготовление на телефон или загружает видео, указывает продукты и собирает шаги. После проверки участники готовят по рецепту, отмечают ингредиенты и переходят от фотографии к соответствующему моменту записи. На главной есть открытый пример. Книги отдельных кухонь и загруженные в них видео доступны только участникам.

## Попробовать локально

Понадобятся Python 3.12+, Node.js 24, npm и, для обработки собственных записей, FFmpeg и FFprobe. Из корня проекта выполните:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
npm --prefix frontend ci
cp -n .env.example .env
```

В `.env` задайте `DEMO_PASSWORD` длиной от 12 символов. Если FFmpeg и FFprobe установлены вне PATH, укажите их абсолютные пути в `FFMPEG_PATH` и `FFPROBE_PATH`.

```sh
.venv/bin/python scripts/dev.py --preview
```

Запускаются интерфейс, Django API и один обработчик видео. Откройте [сайт](http://127.0.0.1:4173) или [учебный рецепт](http://127.0.0.1:4173/example). Если браузерный порт занят, добавьте `--port 4174`. Для разработки с горячей перезагрузкой запустите ту же команду без `--preview`.

## Учебная кухня

| Вход | Что можно попробовать |
| --- | --- |
| `author@demo.local` | Создать рецепт, загрузить видео, добавить ингредиенты, разметить шаги и отправить на проверку |
| `reviewer@demo.local` | Сверить каждый шаг с записью, вернуть рецепт на уточнение или опубликовать |
| `reader@demo.local` | Найти рецепт по ингредиенту и пройти его шаг за шагом |
| `admin@demo.local` | Пройти весь путь в одной учётной записи |

Пароль берётся из локального `.env` при первом создании аккаунтов. Повторный запуск сохраняет существующие пароли и материалы. В примере про кабачок и перец использованы 11,76 секунды настоящей съёмки и три размеченных вручную шага. [Источник видео](demo/README.md).

## Как работает разбор

- Камера и загрузка файла ведут в один редактор. Шаг можно составить вручную даже при отключённом ИИ. При просмотре такого шага браузер извлекает стоп-кадр из его отрезка.
- Видеомодель получает ограниченную выборку кадров после согласия автора. При включённой расшифровке речевые подсказки можно обработать отдельно. В черновике у действий есть ссылки на источник. Короткие движения могут оказаться между кадрами.
- Автор проверяет действие и его фотографии, вписывает ингредиенты, количество и известные параметры. Длительность видеофрагмента показывает, где посмотреть движение. Время выдержки или выпекания указывает автор.
- В примере конфигурации внешняя обработка выключена, указан бесплатный профиль OpenRouter и установлен нулевой предел платных вызовов. Активация требует серверного ключа, разрешения для конкретной кухни и согласия на отправку в интерфейсе. [Настройка OpenRouter](docs/34-openrouter-setup.md).

## Выпуск и эксплуатация

Для сервера подготовлен Docker Compose с HTTPS, PostgreSQL, приватным хранилищем, API и обработчиком. Первая кухня с реальными аккаунтами создаётся командой `kitchen_member`. Инструкция описывает домен, секреты, проверку сервиса и резервное копирование. [Развёртывание](docs/recipe-deployment.md).

Операционное описание продукта находится в [PRODUCT.md](PRODUCT.md). Старые общие инструкции доступны в архиве кухни и по прежним ссылкам. Исторические материалы по распознаванию сохранены в [исходном плане](docs/00-overview.md) и [отчёте о проверке действий по кадрам](docs/37-process-demonstrations.md).

## Проверки

```sh
make check
```

Команда проверяет миграции, API, роли, видео, бюджет ИИ и сборку интерфейса. Локальная база, пользовательские записи и ключи исключены из Git.
