# Рецепты мастера

Кулинарная книга для команды или семьи. Владелец регистрирует свою кухню, приглашает участников и управляет подпиской. Автор загружает видео приготовления, указывает продукты и оформляет шаги. Читатель открывает опубликованный рецепт, отмечает ингредиенты и переходит от фотографии к нужному движению на записи. У каждой кухни свои рецепты, участники и тариф.

## Попробовать локально

Понадобятся Python 3.12+, Node.js 24, npm и, для обработки собственных записей, FFmpeg и FFprobe. Из корня проекта выполните:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
npm --prefix frontend ci
cp -n .env.example .env
```

В `.env` задайте `DEMO_PASSWORD` длиной от 12 символов. Если FFmpeg и FFprobe установлены вне PATH, укажите их абсолютные пути в `FFMPEG_PATH` и `FFPROBE_PATH`.

```sh
.venv/bin/python scripts/dev.py --preview
```

Запускаются интерфейс, Django API и обработчик видео и писем. Откройте [регистрацию кухни](http://127.0.0.1:4173/register) или [пример рецепта без входа](http://127.0.0.1:4173/example). Если порт занят, добавьте `--port 4174` и откройте соответствующий адрес. При запуске без `--preview` доступна горячая перезагрузка.

## Первая кухня

1. При регистрации укажите имя, название кухни, email и пароль от 12 символов. Вы сразу попадёте в свою кухню на тарифе «Старт». Черновик первого рецепта можно создать сразу после входа.
2. Откройте письмо подтверждения и подтвердите адрес на сайте. В локальном режиме письма сохраняются в каталоге `backend/local-mail/`. На сервере их доставляет SMTP. Ссылка подтверждения действует 24 часа, а ссылка восстановления пароля — один час. [Восстановление пароля](http://127.0.0.1:4173/forgot-password).
3. Откройте «Команда» и пригласите автора, проверяющего или читателя. Приглашение действует семь дней. Его можно отозвать, а участнику закрыть доступ. Пользователь с существующим аккаунтом принимает приглашение после входа под указанным адресом.
4. В разделе подписки владелец видит тариф и использованные места. «Старт» включает 5 рецептов и 3 места вместе с владельцем. «Команда» включает 100 рецептов и 15 мест. Для оформления нужна настроенная платёжная форма. [Настройка подписок и тестовой оплаты](docs/customer-billing.md).

Автор может отметить начало и конец действия прямо под видео. Редактор добавит шаг с кадром из этого отрезка и покажет, что ещё заполнить перед отправкой на проверку.

Закладка у опубликованного рецепта сохраняет его в личное «Избранное» на всех устройствах. Во время готовки текущий шаг и отмеченные ингредиенты сохраняются в этом браузере для вошедшего участника. Новая опубликованная версия открывается с первого шага.

## Учебная кухня

| Вход | Что можно попробовать |
| --- | --- |
| `author@demo.local` | Создать рецепт, загрузить видео, добавить ингредиенты, разметить шаги и отправить на проверку |
| `reviewer@demo.local` | Сверить каждый шаг с записью, вернуть рецепт на уточнение или опубликовать |
| `reader@demo.local` | Найти рецепт по ингредиенту и пройти его шаг за шагом |
| `admin@demo.local` | Пройти весь путь в одной учётной записи |
| `operator@demo.local` | Открыть [список клиентских кухонь](http://127.0.0.1:4173/customers), найти клиента и посмотреть тариф и число участников |

Пароль берётся из локального `.env` при первом создании аккаунтов. Повторный запуск сохраняет существующие пароли и материалы. В примере про кабачок и перец использованы 11,76 секунды настоящей съёмки и три размеченных вручную шага. [Источник видео](demo/README.md).

## Как работает разбор

- Камера и загрузка файла ведут в один редактор. Шаг можно составить вручную даже при отключённом ИИ. При просмотре такого шага браузер извлекает стоп-кадр из его отрезка.
- Видеомодель получает ограниченную выборку кадров после согласия автора. При включённой расшифровке речевые подсказки можно обработать отдельно. В черновике у действий есть ссылки на источник. Короткие движения могут оказаться между кадрами.
- Автор проверяет действие и его фотографии, вписывает ингредиенты, количество и известные параметры. Длительность видеофрагмента показывает, где посмотреть движение. Время выдержки или выпекания указывает автор.
- В примере конфигурации внешняя обработка выключена, указан бесплатный профиль OpenRouter и установлен нулевой предел платных вызовов. Активация требует серверного ключа, разрешения для конкретной кухни и согласия на отправку в интерфейсе. [Настройка OpenRouter](docs/34-openrouter-setup.md).

## Выпуск и эксплуатация

Docker Compose запускает HTTPS, PostgreSQL, приватное хранилище, API и отдельные обработчики видео и писем. После подключения домена и SMTP клиенты сами регистрируют кухни. Оператор получает отдельный доступ к списку клиентов. Для платных продаж нужно подключить магазин Dodo Payments и проверить тестовую оплату. [Развёртывание и резервное копирование](docs/recipe-deployment.md) · [Приём подписок](docs/customer-billing.md).

Операционное описание продукта находится в [PRODUCT.md](PRODUCT.md). Старые общие инструкции доступны в архиве кухни и по прежним ссылкам. Исторические материалы по распознаванию сохранены в [исходном плане](docs/00-overview.md) и [отчёте о проверке действий по кадрам](docs/37-process-demonstrations.md).

## Проверки

```sh
make check
```

Команда проверяет миграции, API, роли, видео, бюджет ИИ и сборку интерфейса. Локальная база, пользовательские записи и ключи исключены из Git.
